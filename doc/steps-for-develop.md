* **ابزارها:** نصب Docker، Docker Compose و Python 3.11 روی سیستم توسعه.

### 🚀 قدم‌های اجرایی (Implementation Roadmap)

#### فاز ۱: طراحی دیتابیس و ساختار داده (Database Design)

1. ایجاد دیتابیس PostgreSQL.
2. ساخت جدول کاربران (`users`)، جدول کلمات کلیدی (`keywords`)، جدول Sessionهای تلگرام (`telegram_sessions`) و جدول گزارش لیدها (`lead_logs`).

#### فاز ۲: ساخت هسته شنود تلگرام (Telegram Listener)

1. نوشتن اسکریپت پایه با کتابخانه `Telethon`.
2. تست ورود به اکانت تلگرام با کد تأیید و ذخیره String Session.
3. پیاده‌سازی ایونت `events.NewMessage` برای دریافت پیام از گروه‌ها.
4. اتصال اسکریپت به `Redis` برای ساختن Queue و هدایت پیام‌های جدید به صف.

#### فاز ۳: ساخت موتور پردازش متن (Matching Engine)

1. راه اندازی `Celery Worker` متصل به Redis.
2. نوشتن ماژول نرمال‌سازی متن (حذف فاصله‌های اضافی، اعراب‌زدایی و...).
3. پیاده‌سازی الگوریتم تطبیق کلمات کلیدی (استفاده از Regex یا کتابخانه `RapidFuzz` برای محاسبه درصد شباهت).
4. خواندن کلمات کلیدی کاربران از کش Redis جهت صعود سرعت پردازش.

#### فاز ۴: توسعه سرویس اطلاع‌رسانی (Notification)

1. ساخت ماژول ارسال پیام به `Saved Messages` اکانت کاربر.
2. فرمت‌بندی زیبا برای پیام خروجی (شامل: متن پیام، لینک گروه، آیدی فرستنده، درصد تطابق).

# فاز ۵: توسعه REST API و پنل مدیریت (FastAPI) , dockerizing 

## ریزفاز ۵.۱: زیرساخت دیتابیس و داکر (Database & Infrastructure)
-  راه‌اندازی فایل `docker-compose.yml` برای اجرای PostgreSQL و Redis.
-  کانفیگ Alembic برای مدیریت مایگریشن‌های دیتابیس بدون از دست رفتن داده‌ها.
- redis , postgres images in docker 
## ریزفاز ۵.۲: احراز هویت و هسته REST API (FastAPI Backend)
-  ساخت سیستم ثبت‌نام و ورود با استانداردهای امنیتی (هش رمز عبور با `bcrypt` + صدور توکن `JWT`).
-  ساخت Middleware برای بررسی دسترسی کاربر و نقش‌ها (Admin / User).
-  ساخت Endpoints مدیریت کلمات کلیدی (افزایش، حذف و بروزرسانی).
-  ساخت Endpoints مربوط به لایسنس و اشتراک‌ها (تمدید، استعلام اعتبار).

## ریزفاز ۵.۳: پنل مدیریت و رابط کاربری (Interactive UI)
-  طراحی صفحه لاگین و ثبت‌نام با Tailwind CSS / HTML.
-  **طراحی داشبورد کاربر:**
  - نمایش وضعیت اعتبار لایسنس (تعداد روزهای باقی‌مانده)
  - مدیریت و وارد کردن کلمات کلیدی دلخواه
  - نمایش وضعیت اتصال به تلگرام
  - جدول آخرین لیدهای دریافتی
-  **طراحی پنل مدیریت (Admin Dashboard):**
  - لیست تمام کاربران سیستم
  - دکمه فعال‌سازی/غیرفعال‌سازی دسترسی و تمدید دستی لایسنس

## ریزفاز ۵.۴: منطق اتصال پنل به هسته برنامه (Engine Integration)
-  همگام‌سازی کلمات کلیدی ثبت‌شده در پنل با کش Redis (جهت استفاده آنی ورکرها).
-  پیاده‌سازی منطق چک کردن لایسنس: عدم پردازش لید برای کاربران با لایسنس منقضی‌شده.
-  ساخت جریان (Flow) اتصال اکانت تلگرام کاربر از طریق پنل API/UI.

## ریزفاز ۵.۵: تست سناریوی کامل (End-to-End Testing)
-  **تست سناریو:** ثبت‌نام کاربر جدید → فعال‌سازی لایسنس توسط ادمین → وارد کردن کلمات کلیدی در پنل → دریافت لید واقعی در تلگرام و ثبت آمار در پنل.
